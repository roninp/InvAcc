# Implementation Plan

## Overview

Убрать со страницы «Настройки» заглушки «Проценты брокера за покупку / продажу» и сопутствующий инфо-блок «Настройки брокера пока неактивны…», оставив только актуальные секции (тариф и группы).

Исследование показало: проценты брокера существуют в кодовой базе **только** как декоративные задизейбленные инпуты в `components/settings-page.tsx` (строки 206–232). Никакой бизнес-логики, состояния, хранения или расчётов с комиссиями нет (проверено поиском по `комисс|commission|fee|брокер|процент` — совпадения только в этом файле и нерелевантные). Поэтому изменение чисто UI-уровня и не затрагивает слой логики, хранилище, типы и тесты. Решение заказчика: удалить и поля, и инфо-блок полностью.

## Testing

Новых unit-тестов не требуется (логика не менялась). Стратегия валидации:

1. `pnpm test` — регрессия существующих тестов (`storage`, `portfolio-tier`, `email-validator`, `auth-service`): все должны упасть в 0 изменений.
2. `pnpm build` — проверка TypeScript-компиляции и отсутствия неиспользуемого импорта.
3. Ручная проверка в браузере (`pnpm dev` → страница «Настройки»):
   - секции «Тарифный план», «Использовать группы» и «Группы активов» работают без изменений;
   - блоков «Процент брокера за покупку / продажу» и текста «Настройки брокера пока неактивны…» больше нет;
   - страница «Портфель» и переключение вкладок не затронуты.
